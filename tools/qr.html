QR Coder

Type a link or any text, and a scannable QR code builds instantly. Drop it into a deckbox insert, a binder page, or print it next to a proxy.

  • Quick-pick chips fill in MTJawnny pages for you.
  • The round frame adds a disc and an optional curved label. The code stays square inside, so nothing scannable is lost.
  • Batch mode turns a list of links into a zip of PNGs, each named by its slug.
  • The scannability meter weighs contrast, border, density, and styling. Test a real scan before printing when it dips below Good.
  • Download a crisp PNG, a scalable SVG, or copy straight to your clipboard.
