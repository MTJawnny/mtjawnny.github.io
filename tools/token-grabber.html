Token Grabber

This pulls the tokens and emblems your Commander deck makes straight from Scryfall, so you can print them on the same proxy sheets as the deck.

Search

Type a token name (Goblin, Treasure, Energy, The Ring). Click a result to see every printing, then add the art you like to the queue.

Import deck

Paste a plain-text decklist. The grabber looks up each card and lists every token and emblem it can make. Click a token's name to browse its art, or hit Add for the latest printing.

Download

On Chrome or Edge you can pick a folder and the PNGs save straight into it. Everywhere else, each file downloads on its own. Files are named TokenName_N.png so duplicates stay tidy.

Card data and art are pulled live from Scryfall. Nothing leaves your browser.
